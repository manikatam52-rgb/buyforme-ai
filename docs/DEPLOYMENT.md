# Deployment Guide — BuyForMe AI

## Backend on Render (free tier works)

1. Push the repo to GitHub.
2. Render → **New → Blueprint** → select the repo. `server/render.yaml` provisions the web service with:
   - root dir `server`, build `npm ci && npm run build`, start `npm start`
   - health check `/health`
3. Fill the `sync: false` env vars in the Render dashboard:
   - `MONGODB_URI` (Atlas connection string; allow Render IPs or `0.0.0.0/0`)
   - `PAYPAL_CLIENT_ID`, `PAYPAL_CLIENT_SECRET` (Sandbox)
   - `GEMINI_API_KEY`
   - `CLIENT_URL` = your deployed frontend origin
   - `PRODUCT_SOURCE` = `mock` (or `channel3` with a key)
   - `JWT_SECRET` is auto-generated by the blueprint.
4. Deploy. Verify `https://<service>.onrender.com/health` returns `{ ok: true }`.

## Frontend (Vercel / Netlify / Render static)

- Build: `npm ci && npm run build` · Publish: `client/dist`
- Set `VITE_API_URL` style wiring or point a reverse proxy `/api` at the Render service; the bundled dev proxy is local-only.
- For production, either configure the same-origin proxy on your host or change `client/src/lib/api.ts` `BASE` to your Render URL.

## Post-deploy checklist

- [ ] `/health` shows `paypalConfigured: true`
- [ ] Register + login works (Atlas reachable)
- [ ] Assistant returns products (catalogue source labelled)
- [ ] Sandbox checkout completes end-to-end
- [ ] Transaction appears in dashboard/history
